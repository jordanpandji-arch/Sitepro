# 💎 SitePro Premium Portfolio

Un portfolio d'ingénierie et de design haute précision, conçu avec une esthétique de luxe technologique.

## ✨ Caractéristiques
- **Design Ultra-Premium** : Palette chromatique sophistiquée (Obsidian, Gold Dust, Tech Cyan).
- **Zéro Dépendance** : Construit exclusivement en **HTML5** et **CSS3** pur. Aucun JavaScript, aucun framework.
- **Icônes Custom** : Éléments visuels abstraits générés entièrement via CSS (pseudo-éléments et dégradés).
- **Animations Cinématographiques** : Transitions fluides et apparitions progressives basées sur des courbes de Bézier personnalisées.
- **Totalement Responsive** : Adapté pour une expérience optimale sur tous les écrans.

## 🚀 Déploiement
Le site est optimisé pour être servi comme une page statique.

## 🛠️ Technologies
- HTML5 (Sémantique)
- CSS3 (Variables, Grids, Flexbox, Animations)
- Google Fonts (Inter)
